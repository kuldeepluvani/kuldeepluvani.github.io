# kuldeepluvani.github.io

**The Harness**: a free, interactive field manual on harness engineering for AI agents, plus a portfolio of the harnesses I've built.

**Live:** [kuldeepluvani.github.io](https://kuldeepluvani.github.io)

- Six parts: Agent = Model + Harness, The Loop, Context, Tools & Environment, Guardrails & Trust, Evals & Evolution
- A live, data-driven instrument in every chapter

Static HTML, CSS and vanilla JS. No build step, no frameworks, no trackers. Each page ships a strict Content-Security-Policy.

MYCELIUM · SELF-ENRICHING KNOWLEDGE ENGINE

A knowledge network that grows its own specialists

Most memory systems store what you give them and hope retrieval finds it later. Mycelium works the other way round. It reads a body of notes and code, decides what is true, and organizes itself around what it has learned. Concretely:

  1. Perceive in layers. Each source passes through a pipeline: a cheap structural parse, then a deep extraction of entities, relationships and claims.
  2. Argue before believing. A separate adversarial pass challenges every extracted claim, and a consistency check tests it against what the graph already holds. Only reconciled facts get in, each with a confidence score.
  3. Remember like a living thing. Facts carry provenance and decay over time unless new evidence reinforces them, and duplicates are merged at three levels of similarity.
  4. Grow specialists from structure. Community detection finds dense clusters in the graph, and each cluster becomes a specialist agent that knows its region deeply.
  5. Route through a cortex. A second tier of meta-agents supervises the specialists and decides which ones to consult for a question.

CLAIM · DEVELOPER KNOWLEDGE OS

Memory that writes itself

A single-file, self-bootstrapping memory system for coding agents. Lifecycle hooks capture decisions and discoveries as you work, structure them into an entity graph, and inject a briefing at the start of each session, so every session begins where the last one left off. It stores plain markdown you own.

CLAUDEGOTCHI · DEVELOPER WELLNESS PLUGIN

A harness for the human

A Tamagotchi-style companion that lives in the agent's status line and watches session length, velocity and frustration. Its intelligence runs as deterministic shell hooks at near-zero token cost, and the model only hears about it when you actually need to stop.
